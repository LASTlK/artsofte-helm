# Счётчик посещений

HTTP-приложение на Go с PostgreSQL. Каждый запрос к главной странице увеличивает
счётчик. Значение хранится в базе данных и сохраняется после перезапуска контейнеров.

## Запуск

Нужны Docker с Compose и Make.

```sh
make up
```

Открыть http://localhost:8080. Обновление страницы увеличивает счётчик.

## Команды

| Команда | Действие |
| --- | --- |
| `make up` | Собрать и запустить приложение с PostgreSQL |
| `make db` | Запустить только PostgreSQL на `localhost:55432` |
| `make run` | Запустить БД в Docker и приложение локально; нужен Go 1.24+ |
| `make check` | Проверить HTTP-ответы приложения; запрос к главной увеличивает счётчик |
| `make logs` | Показать логи сервисов |
| `make down` | Остановить сервисы, сохранив данные БД |

Перед `make run` остановить контейнер приложения через `make down`, если он запущен:
оба способа используют порт 8080.

`/healthz` проверяет работу HTTP-сервера, `/readyz` — подключение к PostgreSQL.
Эти запросы не увеличивают счётчик.

Параметры подключения для локального запуска заданы в `compose.yaml` и `Makefile`.
Приложение читает их из переменных `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`,
`DB_PASSWORD`, `DB_SSLMODE`. Адрес HTTP-сервера задаётся через `HTTP_ADDR`.
